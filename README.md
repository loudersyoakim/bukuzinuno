# Buku Zinuno Sinode AFY
Aplikasi lirik lagu rohani digital (Buku Zinuno) untuk jemaat Sinode AFY Nias.

### Fitur Utama:
* Daftar lagu lengkap sesuai nomor Buku Zinuno.
* Pencarian cepat berdasarkan nomor atau judul.
* Mode Gelap (Dark Mode) & Fitur Zoom Lirik (Cubit Layar).
* Fitur Favorit (Ikon Bintang) & Share Lirik ke WhatsApp.
